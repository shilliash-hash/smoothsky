- Airport data is never loaded whole: operations load owner-touched ports only; radar loads 500 size-ranked tier airports plus all worldwide active-flight/ground/activity and owner ports, with scoped supplies in batches of 200. Safe world aggregates are paginated rather than truncated; priority ports survive tier filters. Dispatch nearby RPC returns at most 60 reachable airports including own FBOs; indexed search returns at most 40, code/distance-ranked after 250 ms debounce. Global flights use the safe get_live_radar_flights projection every 5 seconds, never private worldwide flight queries — keeps the 49,000-airport catalogue off the browser.
- ACARS map positions use validated live GPS only; reconnect status and ingestion enforce a strict 30-minute window from server-received telemetry — prevents simulated movement and indefinite resumes.
- Market acquisition blockers are resolved centrally and displayed explicitly; missing country rules resolve to the shared emergency rule without bypassing financial checks — import coverage must not disable funded acquisitions.
- Recruitment defaults/ranges live in economy_config; SQL validates owner-selected rates and applies defaults only to new companies, preserving existing rates and dispatched-flight snapshots.

- Single-flight rentals use atomic owner/tier-checked SQL acquisition and terminal-flight retirement, never deletion; no lease contracts, while ledger charges count in aircraft/company P&L and dividends. Acquisition SQL and all market prices/affordability/confirmations read the live economy multiplier; historical charges remain frozen. Admin can upsert the setting if an environment has no seeded row — keeps economic tuning consistent across environments.

- Hub-and-spoke demand and hub fare bonus are per-destination-size economy_config arrays applied in flight_quote_without_fobs (T1–T2 keep ≥1 pax); unpaved runways use negative surface classification and block non-unpaved_capable aircraft unless no paved field is nearby — one frozen quote path.
- Dispatch previews reuse flight_quote_full in owner-scoped additive RPCs after the 60/40 result limits; alternatives quote only six nearest eligible ports within 150 NM then rank these by margin. Invalid quotes remain null with a reason; cargo settings are part of query identity — avoids economic drift, unbounded quotation work and shared-search regressions.
- Baseline ratings are enforced by a profile default/trigger and replayable historical backfill. Owner training locks the non-personal company before the profile, synchronizes obligations and posts an idempotent company expense; no-company pilots use pilot_post. The profile reads its funding source from owner-scoped my_pilot_profile and invalidates financial/rating caches after purchase — prevents wallet dead ends, duplicate charges and stale affordability.
- FBO base setup and weekly base upkeep scale by a per-airport-size economy_config array in SQL (fob_size_multiplier); UI mirrors it via fboScaledCost, modules stay flat — prevents cheap hub land-grabs.
- Owned/leased aircraft keep persistent fleet_aircraft.current_fuel_gal: a transaction-local target (≥ fuel on board) feeds flight_weight_budget so extra fuel consumes MTOW; the dispatch trigger buys/reserves only the uplift as FUEL_EXPENSE, settlement skips cash fuel and subtracts billed burn from tanks, and the cancel trigger returns uplift plus a FUEL_REFUND once. Rentals keep net-burn billing — one trigger path covers manual and ACARS cancels.
- Administrative cleanup uses self-protected SECURITY DEFINER entry points, revoked internal helpers and transaction-local owner-scoped DELETE-only ledger exceptions; cancellation briefly acts as the aircraft owner for existing refund accounting, then restores admin identity. Auth deletion follows public-data cleanup through the authenticated server action and reports a retryable partial failure — prevents ordinary ledger tampering and incorrect refunds.
- Divert keeps one flight contract with frozen rules and landed-leg history in divert_state; verified ACARS GPS selects the landing airport, revoked helpers settle leg costs, and owner/pilot actions retain payload until final settlement or abandonment. Continuation cancellation refunds only its reservation and restores DIVERTED; lease renewal preserves the lock — avoids premature revenue, fuel refunds for flown legs and duplicate mission settlement.
- Simulator fuel sync: SimBrief plan_ramp (OFP mass units) prefills Target Fuel; ACARS pre-takeoff positions with more sim fuel than target raise target_fuel_gal (≤ tank/MTOW, ≤ airport stock) via revoked ramp_fuel_adjust, billing FUEL_EXPENSE and growing fuel_uplift_cost/fuel_reserved_gal so cancel refunds stay exact — keeps DB tanks equal to the simulator after landing without ACARS client changes.
- Daily fuel markets use one revoked SQL ICAO/UTC-date multiplier across quotes/discovery and continuation; apply FBO discounts afterward and retain dispatch price snapshots for settlement/ramp adjustments — prevents day-boundary price drift.
