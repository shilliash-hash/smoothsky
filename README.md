# SmoothSky

SmoothSky is an independent aviation simulation platform for managing a virtual aviation company.

Users can create a company, establish a base, manage credits, and lease aircraft. The platform records balance changes in a transaction history. It uses its own database and does not depend on SimFly or external APIs.
